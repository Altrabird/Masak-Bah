# Masak Bah! — Dapur Malaysia

Permainan memasak 3D dalam Bahasa Melayu: 50 resipi Malaysia (hidangan utama,
pencuci mulut, warisan, Sabah & Sarawak, minuman), 15 jenis langkah memasak,
cipta chef sendiri, kedai, Cabaran Juri dan lagu-lagu makanan.

**Main sekarang:** https://altrabird.github.io/Masak-Bah/

Paling baik dimainkan di komputer (Chrome / Edge) atau telefon dalam kedudukan
melintang. Muat turun kali pertama ~50 MB.

Repo ini hanya mengandungi binaan WebGL (Unity 6). Penghargaan: model Kenney
dan watak manusia Quaternius (CC0), fon Fredoka & Varela Round (SIL OFL),
suara ms-MY (edge-tts).
